# Fuentes utilizadas

1. `proyecto_react.zip`
   - Proyecto React Native/Expo aportado por el usuario.
   - Se usó como punto de partida para conservar la idea de Login/Home y la organización inicial.

2. `Skyed_GitHub.zip`
   - Proyecto SKYED original.
   - Se usó para conservar la identidad visual, nombres de páginas, textos funcionales y recursos gráficos.

Esta entrega NO incorpora Laravel ni PostgreSQL.
